# Personal Portfolio Website

A clean, responsive personal portfolio website built with HTML, Tailwind CSS, and JavaScript.

## Features

- Modern, minimalist design
- Dark/light mode toggle
- Responsive layout
- Animated typing effect that cycles through "developer.", "Coder", and "Nabhaan"
- Ionicons integration for icons

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Typed.js for text animation effects
- Ionicons for UI icons

## Project Structure

- `src/index.html` - Main HTML file
- `src/output.css` - Compiled Tailwind CSS
- `src/script.js` - JavaScript functionality for dark mode toggle and typing animation

## Getting Started

1. Clone the repository
2. Open `src/index.html` in your browser

## Customization

You can customize the portfolio by:
- Updating the name "Nabhaan" in the HTML
- Modifying the navigation links (Home, About, Project, Contact)
- Changing the typing effect strings in script.js
- Adjusting colors (currently using orange as accent color)
- Adding your own content to the sections

## Dark/Light Mode

The portfolio includes a toggle for switching between dark and light modes, accessible via the moon/sun icon at the bottom of the page. The toggle functionality is implemented in script.js.
